# ShoppingCart
A simple command-line based shopping cart system built in Python.  
Users can browse products, add/remove items from a cart, and complete checkout with multiple payment and delivery options.

---

## Features
- View available products
- Add multiple products to cart
- Remove items or adjust quantities
- View cart with total price calculation
- Checkout system with:
  - Customer details input
  - Multiple payment methods:
    - Credit/Debit Card (with masking)
    - PayNow (phone validation)
    - Cash on Delivery
  - Delivery options (Pickup / Home Delivery)
- Input validation for secure and clean data handling

---

## Tech Stack

- Python 3
- Standard Library (no external dependencies)

## Security Features
- Card numbers are masked (e.g. **** **** **** 1234)
- Input validation prevents invalid payment data
- Phone and card formats are verified
